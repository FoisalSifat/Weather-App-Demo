🌦️ AKASH | Modern Weather Experience
AKASH is a high-end weather dashboard designed for clarity, precision, and aesthetic appeal. It bridges the gap between technical data and a premium user experience, featuring a "Midnight" design language with nature-inspired accents.

✨ Key Features
Real-time Tracking: Live weather updates using the OpenWeather API.

Aesthetic UI: A deep charcoal and "Forest Green" color palette designed for eye comfort.

Dynamic Visuals: Glassmorphic cards and futuristic animations that reflect current conditions.

Responsive Design: Fully optimized for mobile, tablet, and desktop viewing.

Local Focus: Tailored to provide highly accurate data for regional and global locations alike.

🛠️ Tech Stack
Frontend: HTML5, Tailwind CSS (Custom Theme), JavaScript (ES6+).

API: OpenWeatherMap API for real-time meteorological data.

Icons: Lucide-React / FontAwesome for crisp, scalable weather iconography.

Hosting: Deployed via Netlify.
